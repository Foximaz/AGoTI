# Async Graph of Thought Interface

This is a framework for constructing and running Graphs of Operations for LLMs.

# Examples

Examples of usage can be found in `examples` directory.

# Modules

- `operations.py` - operation class and basic operations
- `goo.py` - graph of operations class and GoO json parsing
- `thoughts.py` - thought class
- `model.py` - LLM model class
- `utils.py` - node and graph classes as well as some async classes
- `draw.py` - GoO rendering
